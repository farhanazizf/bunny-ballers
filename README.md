# Bunny Ballers

Situs klub basket anak dan remaja usia 6–18 tahun di MS Sports Arena BSD. Halaman ini untuk orang tua: lihat program, jadwal, galeri, lalu daftar trial via WhatsApp.

Live: [https://farhanazizf.github.io/bunny-ballers/](https://farhanazizf.github.io/bunny-ballers/)

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS 3
- i18n ID / EN
- GSAP untuk motion

## Lokal

```bash
npm install
npm run dev
```

Tes dan build:

```bash
npm test
npm run lint
npm run build
```

## Deploy

Repo ini deploy otomatis ke **GitHub Pages** (gratis) setiap `push` ke `main`, lewat `.github/workflows/pages.yml`.

Setelah Actions pertama sukses, situs ada di:

`https://farhanazizf.github.io/bunny-ballers/`

Kalau 404, buka repo → **Settings → Pages → Source: GitHub Actions**.
